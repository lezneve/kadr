# kadr 0.1.0-rc.1 / ручна перевірка

~15 хвилин. звичайний обліковий запис і звичайний термінал (не «від імені адміністратора»). позначайте ✔ / ✘ і пишіть коротку примітку до кожного ✘ — виправляємо лише підтверджене.

зберіть пакет: `powershell -NoProfile -ExecutionPolicy Bypass -File tools\release.ps1 -SkipSmoke` → `dist\`.

## 1. встановлення

| | дія | очікування | |

## 3. налаштування

| | дія | очікування | |
|---|---|---|---|
| 3.1 | трей → settings | вікно з іконкою kadr; tab по рядках, мітки обрізу йдуть за фокусом | |
| 3.2 | клік по «capture region», нова комбінація (наприклад ctrl+alt+s) | нова працює, стара ні | |
| 3.3 | у записі: esc; backspace; win+shift+s | esc лишає стару; backspace вимикає («off»); win+shift+s — червоне «used by another app» | |
| 3.4 | send to → clipboard, file, both | кожен варіант робить саме це | |
| 3.5 | folder → вибрати іншу папку | наступний знімок там | |
| 3.6 | file name: ввести `:` | червона помилка замість передперегляду, нічого не зберігається; прибрати `:` — передперегляд повертається | |
| 3.7 | start with windows вимкнути / увімкнути | після перезапуску windows kadr стартує (або ні) відповідно | |
| 3.8 | перемкнути тему windows світла ↔ темна при відкритих налаштуваннях | вікно, заголовок і іконка трею змінюються | |
